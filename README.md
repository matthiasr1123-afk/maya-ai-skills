# Maya AI Skills Pack

15 reusable Markdown instruction files: 10 Maya Finds skills and 5 general skills. These are **instruction templates**, not executable plugins or installed ChatGPT skills. Copy relevant instructions into your project or compatible agent skill environment. GitHub storage alone does not activate them.

For Maya Finds, prioritize realistic, coordinated, fashion-first short videos and views/retention. Keep product research and prompt creation as separate roles.

Never execute unknown third-party repository scripts without reviewing permissions and code.
