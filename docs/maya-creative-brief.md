Rank recent posts and match their captions or visible garments to exact approved references. Prioritize products with the strongest recent views, especially repeated high-view posts, while accounting for post age. Choose from those products before applying crop or styling tests. Report the view counts behind the picks. If live data is unavailable, use the latest verified figures and identify their date.

## What to make next
Editor: Use the approved product-first hook and existing type treatment as the control. On two comparable takes of the same product, test a straight cut to a detail shot at 1 second versus 2 seconds. Hold runtime, shot order, words and styling steady. Use a detail shot only when accurate footage exists. Primary outcome: early retention at the same elapsed time if available, otherwise comparable average watch time in verified units. Check attributed sales separately.
Image creator: Use an approved leopard set reference if available. Test close versus wider framing in the same seated setup. Keep the garment, pose, lighting and background consistent. Use the same edit for both. Compare attributed items per 1,000 views and report counts alongside rates. If commerce data is missing, report attention only. Run this separately from the editing test.
After the crop test, rotate through camera angle, background, product, pose and opening frame, choosing one question per comparison.

## Standing workflow for every Run Maya request
Use the current creative brief, the latest relevant Gemini learning entries and exact approved product references. Produce four separate 9:16 PNGs. Make styling differences clearly visible across the batch. Within a controlled comparison, keep everything except the tested variable consistent.

Generate one image at a time. Inspect the garment against its reference, including color, print, seams and fit. Check anatomy, framing and artifacts. Correct any failure and inspect again before approval. Save each approved PNG with its individual 7–10 second Gemini prompt before starting the next image. Use stable batch and image identifiers so an interrupted run can resume at the first unfinished image without regenerating approved work. Complete all four autonomously and deliver each file with its copy-ready prompt. Ground motion in the latest reviews and the actual starting pose. Captions wait until video editing.

For Gemini’s “I can’t make videos of real people in situations like that” error on an AI-generated adult fashion still, start with the original image as frame one. Describe the model accurately as fictional, begin a visible handheld camera move immediately, and add one small natural pose movement that fits the still. Keep the full product visible and preserve garment details. The November 27 SHAPELLX lace-tights entry in `gemini-generation-learning-log.md` has the exact prompt the user confirmed worked.


## Winning reference frames required for Run Maya

Use only a specific product-video framing the user has identified as a winner or that verified results connect to an identifiable source frame. Inspect that actual frame before generation. Match camera height, tilt, distance, pose, product scale and crop, including the visible garment landmarks. A mirror or car setting alone does not qualify. Views for a caption alone do not verify an angle. Keep styling variations secondary. If a new product lacks a winning source frame, use an eligible product again. Check every output side by side against its source before delivery.
