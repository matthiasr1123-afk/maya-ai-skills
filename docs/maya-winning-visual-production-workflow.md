## Visual library

V2 MIRROR FULL FIT: head cropped or face obscured, full-body outfit, warm bedroom mirror, stable proportions, natural posture and small weight shift.

V4 COZY SEATED HOME: bedroom/lounge pose, product-dominant natural iPhone look.
These are hypotheses supported by early results, not guaranteed viral templates. Adapt each to actual product: don't put shoes or handbags in a leggings-specific pose where product isn't visible.

## Product gate (Kalodata periodic, not daily mandatory)
Find replacement candidates only as needed. Verify exact TikTok Shop SKU and seller reference; account affiliate eligibility and commission; rating/review volume and recent negative themes; current 7/30d sales velocity, creator competition, active paid ads/GMV Max evidence, stock, variant and price. Reject or flag low-rated/low-margin items; no invented figures. Prioritize high quality, margin and visual suitability over views alone. Confirm before generation.

## Batch SOP
1. Read current HQ, learning log, performance snapshot, viral-video-analyst, gemini-prompt-engineer, fashion-director.
2. Confirm exact product references and visual attributes. Generate multiple separate 9:16 accurate stills based on V1–V4, checking pattern, color, logo, garment cut, anatomy, crop, duplicates, labels, claims.
3. Deliver one copy-paste Gemini image-to-video prompt per still, 6–8 sec target, minimal natural motion, preserve first frame and exact SKU; silent.
4. User generates videos in Gemini and uploads batch. Suggested Drive structure: 01 Product References; 02 AI Images Ready for Gemini; 03 Gemini Videos to Edit; 04 Edited Videos Ready to Post; 05 Posted Videos + Performance. Folder creation and watcher not yet implemented.
5. Review actual files, mark POST/REGENERATE/DITCH, edit verified footage with short natural readable safe-area hooks, palette-matched overlays, silent exports, privacy metadata cleanup preserving AI provenance; deliver filenames, caption, hashtags and verified commercial audio where possible.
6. Schedule only after user approval and validated media hosting/integration. Metricool scheduling possible if supported; direct native TikTok draft creation not established.
7. Track per-video views 2h/24h/48h, retention, click counts/CTR where available, attributed items sold/GMV/commission; compare creative with same SKU where possible. Never assume sales from profile views alone.

## Operating principles
Minimize user steps: user supplies/approves product and generates Gemini videos; assistant handles still creation, prompts, QC, edit package, analysis. Don't auto-generate images merely because workflow was saved; user triggers production. No blind spam, no false quality claims, no duplicate uploads, no unsupported claims about automated folder monitoring or draft publishing.
