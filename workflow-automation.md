# Workflow Automation

## Purpose
Organize product shortlist -> reference analysis -> prompt -> generation -> QC -> publishing -> analytics. Keep product research separate from prompt writing. Never claim uploads, posts, or scheduled tasks happened without tool confirmation.

## Execution
1. Confirm available inputs and tools.
2. Deliver the requested output directly.
3. State missing evidence or blockers briefly.
4. Keep work consistent with the user’s latest instructions.
